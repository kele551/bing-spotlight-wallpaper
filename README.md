# 微软壁纸助手 · 必应每日一图 + Windows 聚焦 双图源自动换壁纸

Windows 桌面壁纸自动轮换工具。两个官方图源：**必应每日一图** 和 **Windows 聚焦**（微软官方 4K）。
**绿色单文件版**：双击即用，不用安装、不写注册表、不需要管理员权限。删掉文件夹 = 彻底卸载。

## 给朋友用（就一步）

1. 拿到 `微软壁纸助手.exe`
2. 双击它，菜单就出来了

想让它在后台默默换壁纸，菜单里按一次 **[A]**。
不需要管理员，不装计划任务，只是往 Windows「启动」文件夹放一个快捷方式。

## 功能

| 能力 | 说明 |
|---|---|
| 必应每日图 | 每天第一次运行，下载并切换到必应当前官方图 |
| 离线补漏 | 几天没开机，**错过的每一天必应壁纸自动补下载**，一张不少（≤7 天走官方接口，更早走归档源） |
| 聚焦轮换 | 按设定间隔（默认 30 分钟）自动换一张聚焦壁纸；同库内不重复 |
| 队列机制 | 库内图片洗牌成队列依次发放，发完自动再下载 6 张重洗一轮，不会"挑不出图卡死" |
| 收藏 | 按 `[F]` 收下当前这张；收藏夹里可回看、可设成「只在收藏里轮换」 |
| 填充方式 | 填充 / 适应 / 拉伸 / 居中 / 平铺 / 跨区，设置里选 —— 不再被程序写死成"填充" |
| 桌面快捷方式 | 自动在桌面建好；exe 挪了位置自动改指，覆盖新版后图标自动刷新（设置 [6] 可关） |
| 往期归档 | 可按年月批量下载 2021-02 至今的必应 4K 原图（来源 niumoo/bing-wallpaper） |
| 路径自适应 | 首次运行列出所有**能写**的盘让你挑（非系统盘优先、按可用空间降序）；写不进去的盘会被标出来并说明原因 |
| 无黑窗 | exe 是 GUI 子系统程序，后台模式一个控制台都不创建（原理见下） |
| 绿色 | 所有状态都在 exe 同级目录里，不碰系统 |

## 壁纸存哪：默认是「图片」文件夹里的「壁纸」

默认位置是**系统「图片」文件夹里的「壁纸」文件夹**，下面两个子目录：

```
<图片文件夹>\壁纸\必应     必应每日一图
<图片文件夹>\壁纸\聚焦     Windows 聚焦
```

文件夹不存在会自动建。取的是图片文件夹的**真实位置**（可以把图片库挪到任意盘，
程序跟着走）。

**一个例外：图片文件夹在系统盘时，默认挪到系统盘以外。** 壁纸每天都攒，几年下来
好几个 GB，放 C 盘容易把系统盘撑满。这时默认位置是 `<非系统盘>\图片\壁纸`，
挑盘规则沿用 `Get-BwPickRoot`（非系统盘优先、可写优先、可用空间降序）。
只有系统盘的机器才用 `<图片>\壁纸`，并且会在向导里说明。

## 壁纸可以自己删、自己挪

库里的图随时可以删除、移到别的文件夹、拷走 —— 这是设计上就允许的，程序不受影响：

| 你做的事 | 程序的反应 |
|---|---|
| 删掉几张 | 不再排进轮换；**也不会被重新下载回来**（补漏有水位线，只往前不后退） |
| 把整个库挪走 | 菜单提示"图是不是被移到别处了"，引导到设置里把位置指过去 |
| 正在用的那张被移走 | 如实写"这张已经不在库里了"，换一张就更新 |
| 库目录暂时读不到（移动硬盘没插） | 不动队列，不会把轮换进度清掉 |

口径统一：只认 `必应/`、`聚焦/` 这两个目录**这一层**的 `.jpg`，不往子目录里钻。
这样"库里有几张"永远等于"能轮换几张"，不会对不上账。

## 选盘时：所有盘都列出来，写不进去的也能一键修

首次运行（或菜单 `[S]` 设置）会把机器上的盘**全部列出**（`非系统盘 → 系统盘`，
同档按可用空间从大到小），C 盘也在列表里，只是标成"系统盘, 不推荐"。
**列表只排序，不筛选** ——
这是刻意的设计：一个盘能不能写是**每台机器各自的权限设置**，不是这个程序的规则，
所以不能因为某台机器上写不了，就把那个盘从所有人的列表里删掉。

个别盘（常见于用第三方分区/格式化工具做出来的数据盘）根目录**没给普通用户"新建文件夹"的权限**，
选中它时程序会说明情况并给两条路：

```
   [1] 现在就修好它 —— 用一次管理员权限建出 <盘>:\微软壁纸助手
       并只给这一个文件夹授权 (不动盘根, 不动盘上别的目录;
       删掉这个文件夹就等于完全回退, 不留任何权限改动)
   [2] 我自己换一个位置
```

修复做的事情，就是把 Windows 装机会给数据盘根目录写的那条授权
（`Authenticated Users:(OI)(CI)(M)`）**只**应用到这个程序自己的文件夹上。
盘根保持原样，盘上别的目录一概不碰。删掉 `<盘>\微软壁纸助手` 就等于完全回退。

已经修过的盘，之后每次运行都会直接认成"能用"，不会再问第二遍
（判据是 `Test-BwDriveUsable`：盘根可写 **或** `<盘>\微软壁纸助手` 可写）。

## 双击之后发生什么

```
双击 微软壁纸助手.exe
   |
   +-- 首次: 在旁边建「微软壁纸助手数据」目录, 释放 core.ps1 / menu.ps1
   |         然后走一遍首运行向导 (确认保存位置, 下载今天的必应图 + 6 张聚焦)
   |
   +-- 之后: 直接显示菜单

菜单里按 [A] 打开「开机自动换」
   |
   +-- 往 启动文件夹 放一个快捷方式, 指向 微软壁纸助手.exe --daemon
       (不需要管理员)
   |
   +-- 下次登录后, 这个 exe 以 GUI 子系统身份在后台跑,
       完全不创建控制台窗口 -> 一个像素都不会闪
```

## 无黑窗的原理

计划任务 / 启动项直接启动 `powershell.exe` 时，`-WindowStyle Hidden` 救不了它——
因为 powershell.exe 的 PE 子系统是 **CONSOLE**，Windows 会**先创建控制台窗口、再执行隐藏**，必然闪一下。

本项目的做法是把启动器做成 **GUI 子系统** 的 exe：

| 宿主 | PE 子系统 | 结果 |
|---|---|---|
| powershell.exe | CONSOLE | 会分配控制台 → 闪窗 |
| wscript.exe | GUI | 不会闪（旧方案） |
| **本 exe（--windowed）** | **GUI** | 不会闪；需要菜单时才自己 `AllocConsole()` |

顺带解决了另一个隐患：微软已宣布逐步弃用 VBScript，本方案不依赖 VBS。

```
========== 微软壁纸助手 v1.4.0 ==========
 今日必应: 已切    下次自动换: 10:30    开机自动换: 开
 壁纸库: 必应 135 张 · 聚焦 124 张 · 待换队列剩 118 张
 保存位置: F:\我的图片\壁纸
 当前壁纸: 2026-09-17_一座悠闲的小岛_windmillfuerteventura.jpg

 —— 换图 ——
  [1] 立刻换一张 (聚焦)
  [2] 换上今天的必应每日一图
  [3] 再抓一批新聚焦
 —— 壁纸库 ——
  [4] 从库里挑一张
  [5] 随便来一张
  [6] 打开壁纸文件夹
 —— 补图 ——
  [7] 补下最近错过的必应 (几天没开机)
  [8] 下载往期必应 (2021 年至今, 4K)
 —— 其他 ——
  [F] 收藏当前这张 / 取消收藏
  [S] 设置
  [A] 开机自动换壁纸  开 / 关
  [L] 查看运行日志
  [Q] 退出
```

`[4] 从库里挑一张` 的列表里，收藏过的图前面标 ★，输入 `f3` 就是收藏 / 取消收藏第 3 张。

`[S] 设置` 是一个子菜单，当前值直接印在旁边，改哪项选哪项：

```
========== 设置 ==========
  [1] 换图间隔        每 30 分钟换一张
  [2] 每轮抓几张      一次抓 6 张聚焦备用
  [3] 壁纸保存位置    F:\我的图片\壁纸
  [4] 壁纸填充方式    填充
  [5] 收藏夹          12 张 · 只在收藏里轮换 关
  [q] 返回
```

`[5] 收藏夹` 里可以回看收藏、设为壁纸、`r3` 移出第 3 张，按 `[s]` 切换「只在收藏里轮换」
（开了之后自动换图只从收藏里挑；收藏里一张能用的都没有时，会先退回整个库，不会卡住不换）。

## 配置项（config.json）

| 字段 | 含义 | 默认 |
|---|---|---|
| `bing_save_dir` | 必应壁纸库目录 | 默认 `<图片文件夹>\壁纸\必应`（图片文件夹在系统盘时改为 `<非系统盘>\图片\壁纸\必应`） |
| `spotlight_save_dir` | 聚焦壁纸库目录 | 同上，`\聚焦` |
| `resolution_mode` | 必应下载分辨率：`auto` 跟随屏幕（按**物理像素**判断）/ `uhd` 固定 4K | `uhd` |
| `wallpaper_style` | 桌面填充方式：`fill` 填充 / `fit` 适应 / `stretch` 拉伸 / `center` 居中 / `tile` 平铺 / `span` 跨区 | `fill` |
| `fav_only` | 只在收藏里轮换（收藏名单存在 `state.json` 的 `favorites` 里） | `false` |
| `cycle_minutes` | 换图间隔（分钟） | `30` |
| `spotlight_per_cycle` | 队列发完后每轮补货张数 | `6` |

## 自己打包

```bash
python -m pip install pyinstaller
python build-exe.py
```

## 可选：改用计划任务（不用常驻进程）

绿色版默认用「启动文件夹 + 后台常驻」。如果你更喜欢计划任务那种"跑一次就退"的方式：

```powershell
# 以管理员身份运行
powershell -ExecutionPolicy Bypass -File install-task.ps1
# 卸载
powershell -ExecutionPolicy Bypass -File install-task.ps1 -Uninstall
```

两种方式**不要同时开**，否则两边会轮流抢壁纸。

## 常见问题

- **双击没反应**：安全软件拦了 PyInstaller 生成的 exe，加信任即可。程序只从 bing.com 和微软官方接口下图，无任何上传行为。
- **中文乱码**：系统「非 Unicode 程序语言」需设为「中文(简体, 中国)」。
- **我把图片删了 / 移到别处了，会不会出问题**：不会，这是设计上就允许的。删掉的图不会再被排进轮换，
  也不会被重新下载回来（补漏只补真正错过的日子）；想接着用移走的那些图，在 `[S] 设置` 里把保存位置指过去。
- **某个盘提示"现在写不进去"**：那是**这台机器**的权限设置，不是程序不支持这个盘，盘上别的目录也可能照样能写。
  Windows 装机时会给数据盘根目录写上"普通用户可修改"；用第三方分区/格式化工具做出来的盘常常没有这条，
  于是盘根建不出文件夹。首次运行向导（或菜单 `[8]`）里选中这类位置时，程序**不会把它藏起来**，
  而是给你一条路：按 `[1]` 一键修复 —— 以管理员权限**只**建出 `<盘>\微软壁纸助手`，
  并**只**给这一个文件夹授权，不动盘根、不动盘上别的目录；把这个文件夹删掉就等于完全回退。
  想自己动手也行（管理员命令行，把 `<盘>` 换成你的盘符）：
  `icacls "<盘>:\微软壁纸助手" /grant "Authenticated Users:(OI)(CI)(M)"`
- **改了保存位置 / 挪了文件夹**：绿色版不用重装，直接挪；如果之前装过计划任务，重新跑一次 `install-task.ps1` 修路径。
- **日志**：`wallpaper.log` 超过 256 KB 自动裁剪，只留最近 200 行。
- **exe 放哪儿有要求吗**：没有，桌面、U 盘、随便哪个文件夹都行，程序不挑地方。
  唯一的讲究是挪 exe 时把同级的「微软壁纸助手数据」目录一起挪 —— 设置、换图进度、
  收藏都在里面。忘了挪会被当成新用户重新问一遍壁纸存哪，把老目录拷回来即可；
  开机自动换那个快捷方式不用管，打开菜单时会自动找到 exe 的新位置。
